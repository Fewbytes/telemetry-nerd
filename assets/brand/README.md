# Brand assets

SVG sources are hand-edited; everything in `dist/` is generated by `just brand`.

| File | Use |
|---|---|
| `logo.svg` | Primary logo: the nerd at the chalkboard. Raw trace in chalk, smoothed trace in yellow; histogram and fitted bell in the lenses. |
| `icon.svg` | Face alone, for avatars, README and app icons (64 px and up). |
| `favicon.svg` | Simplified face drawn on a 32-unit grid for 16 and 32 px. Not for larger sizes. |
| `og.svg` | 1200×630 social card. Embeds `logo.svg`; text uses system fonts (Avenir Next, then Helvetica). |
| `wordmark.svg` | Horizontal lockup: `icon.svg` beside "Telemetry Nerd". Header/inline use. |
| `wordmark-stacked.svg` | Stacked lockup: `icon.svg` above "Telemetry Nerd". README / square placements. |

Wordmark typeface: Avenir Next (Helvetica Neue, Helvetica, Arial as fallbacks), 700 weight — the
same stack `og.svg` already set as the de facto brand font; `wordmark.svg` and
`wordmark-stacked.svg` bake it in as SVG text, so every placement (site header, README) renders
it the same way regardless of the viewer's own fonts.

Colours are fixed and work on light and dark backgrounds:

| Role | Hex |
|---|---|
| Ink (outlines) | `#1b2124` |
| Face | `#f2b544` |
| Lens | `#ffffff` |
| Lens plots | `#1f6f8b` |
| Chalkboard | `#23453b` |
| Chalk | `#f1f4ee` |
| Yellow chalk | `#ffd36b` |
